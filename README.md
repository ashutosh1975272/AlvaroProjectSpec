# AlvaroProjectSpec

Cut Deluxe — automation-layer specification (Base44 mobile-barber booking app).

This repository contains the spec folder only: the working spec, the
DOCX-derived source-of-truth extract, the full traceability ledger, the
decision register, the skills/methodology documentation, and 18 Base44-ready
implementation tickets (01 scaffolding → 18 CRM) in DOCX §12 delivery order.

Source of truth: `Cut_Deluxe_Functional_Specification_Atul.docx` (October 2026),
mirrored textually in `spec/appendix-docx-extract.txt`.

- `spec/README.md` — folder map and reading order
- `spec/SKILLS.md` — agent skills used (mattpocock: setup/grill/to-spec/to-tickets;
  morluto/rea evidence discipline) and how to continue the workflow
- `spec/tickets/` — the 18 tickets, each with what to build, blocked-by,
  `ready-for-agent [BETA]` status, branch, Requires, how to test, what you
  see, and acceptance criteria
